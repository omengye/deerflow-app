# Waku 移动端迁移验收

## 自动验证

执行 `gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`。协议基线为 deerflow-api 的 Waku v10；后端协议升级时更新跨语言契约与对应测试。

本次本地验证（2026-10-27）：115 项 JVM 单元测试，0 失败、0 错误、0 跳过（包含会话标题生成／恢复、目录与事件竞态、Unicode 摘要、后台宽限期、前台服务持有状态、暂停/超时隔离、Full Access、工具展示及弱网恢复）；Lint 与 Debug APK 构建通过。环境为 Windows、Gradle 9.5.1、Android SDK 36 / build-tools 36.0.0，JDK 25（源码目标 Java 17）。Lint 仍保留工具链升级提示及图标/KTX 建议，不设掩盖错误的 baseline。

## 真机与服务端联调

下列为待执行的真实网络验收项，不应把 JVM 测试通过描述成这些场景已实测通过。使用受控测试任务，避免用有外部副作用的真实业务验证重试。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| Full Access 新会话 | 安装更新后新建任务并调用普通工具 | 后端策略为自动授权，不逐次弹卡 |
| Full Access 旧会话 | 结束旧轮次，在原 ask 会话发送下一条消息 | 等待后端权限切换确认后才发送，不只改本地标签 |
| 权限设置断网 | 权限切换请求后立即断网 | 保留消息，明确未发送，不自动重放权限变更或 prompt |
| 底部连接提示 | 已连接时运行任务、等待授权，再断网 | 正常状态隐藏连接按钮；断线显示恢复入口；未知提交保留核对操作 |
| 工具展示 | 连续调用不同工具，观察执行中、完成、失败及恢复后的历史 | 同一调用更新原行，显示名称和独立状态；不显示参数、返回内容或展开箭头 |
| 新会话标题 | 发送首条消息，再继续对话 | 列表和顶部显示一致摘要，后续消息不覆盖手动或已有标题 |
| 旧会话标题 | 打开旧版创建的无标题历史，包括无本地缓存的会话 | 只读补齐标题，不重发消息、不替换已有正文 |
| 跨端改名 | 桌面修改手动／自动标题，手机收到目录刷新 | 手动名称立即更新；自动标题核对完整快照后更新，旧游标不会覆盖新事件 |
| 中文长标题 | 首条消息包含长中文句子、空白、emoji | 摘要截断正常，标题单行省略，不挤占操作按钮 |
| 正常多端 | 桌面创建会话，手机进入同一会话 | 历史和新事件一致，手机不会替换桌面 runtime |
| 流式断网 | 输出途中切飞行模式，再恢复 | 本地文本保留，重放后无重复/缺失，不重发 prompt |
| 网络切换 | Wi-Fi 与移动网络来回切换 | 自动检测连接变化，保留原会话并补事件 |
| 半开连接 | 代理静默丢弃 TCP 数据、不发关闭帧 | 心跳/超时结束陈旧连接，退避重连 |
| 回执丢失 | 服务端接受 prompt 后丢响应 | 不自动再次提交；按消息 ID 核对，无法核对时锁定并显示原文 |
| 进程退出 | 已显示部分流式内容时停止 app 进程，再打开 | 从原子快照恢复内容与游标，不丢前缀，不自动发送 pending 操作 |
| 短暂后台 | 空闲时切后台，60 秒内返回 | 保持原连接，不重复握手或发送命令 |
| 空闲息屏 | 无任务时切后台超过 60 秒，再返回 | 宽限结束后暂停；返回自动重连 |
| 任务后台 | 提交／上传后立即切后台或息屏，等待超过 60 秒 | 任务继续，前台服务持有连接；返回检测连接并补齐 |
| 完成通知 | 后台任务结束或需要授权／输入 | 状态通知可返回 App；历史重放不重复通知 |
| 暂停后台接收 | 点击常驻通知中的暂停操作 | 关闭后台订阅，不取消服务器任务；返回 App 恢复 |
| 系统时限 | 模拟 dataSync 超时 | 及时停止服务，无 ANR 或无限重启；服务器任务保留 |
| 通知权限 | 拒绝通知权限后使用 App，再从设置开启 | 前台功能正常；权限状态不会使连接循环重启 |
| 进程终止 | 后台运行时强行停止 App，再打开 | 不自动发送旧命令，读取缓存并恢复服务端状态；终止期间不承诺通知 |
| 双端审批 | 手机和桌面看到同一审批，在一端处理 | 不自动批准、不自动重发；明确展示 v10 跨端完成通知的限制 |
| 审批断网 | 提交审批后立即断网 | 保留结果待核对状态，不能因重连自动重复提交 |
| 取消竞态 | 点击停止时任务恰好完成 | 不把断开/ACK当作取消完成，以最终执行事件为准 |
| 服务重启 | 流式途中重启 daemon | epoch变化触发重新读取；无法证实的执行结果保持待核对 |
| 切换服务器 | 在设置中切换地址或Token | 缓存与旧socket隔离，不把旧会话发给新服务器 |
| 附件弱网 | 上传途中断网 | 不能悄悄丢弃附件后发送文本；保留输入或明确报告未发送 |
| 存储故障 | 模拟磁盘不足/快照损坏 | 明确错误，不静默重置游标或丢弃未确认命令 |
| 认证/协议 | 错误Token或非v10服务端 | 停止自动重试，引导修正配置 |

## 服务端边界

本次 app 分支不改动 deerflow-api 工作区。当前服务端的请求去重缓存不是跨重启事务日志，事件重放是 runtime 生命周期内的日志，前台审批没有统一的 pending snapshot / resolved 广播。客户端以只读核对和显式待处理状态保护这些边界，不声称服务端具备尚未实现的保证。

旧 AG-UI 本地记录只读保留；旧执行检查点不会被当作新的 Go 会话恢复。
